# Security Policy

## Supported Versions

Only the latest GitHub Release is supported with security fixes.

## Reporting

Do not publish account data, Apple Music tokens, wrapper-manager instance data, `config.toml`, qcow2 images or personal paths in a public issue.

Report a suspected vulnerability through GitHub private vulnerability reporting when it is enabled for the repository. Otherwise, contact the repository owner privately before opening a public issue.

Include the plugin version, Windows version and a minimal reproduction. Remove tokens, usernames, paths and downloaded media from logs and screenshots.
